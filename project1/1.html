Fundamentals of Design - 3 Session Micro-Course

Course Description: :

This micro-course offers a concise and structured introduction to fundamental design principles. Across three sessions, participants will gain essential knowledge in color theory, layout composition, and creative design thinking, with a focus on practical and applicable skills.

Objectives Learning :

  1. Session 1: Color Theory
    • Understand basic color concepts and relationships
    • Use color effectively to create visual harmony
  2. Session 2: Layout & Composition
    • Learn core layout principles such as balance and alignment
    • Design clear and well-structured visual compositions
  3. Session 3: Creative Design Application
    • Develop creative problem-solving skills
    • Apply design principles in a practical mini project

Q1: Who is this micro-course for?

This course is designed for beginners interested in learning the fundamentals of design. No prior experience is required.

Q2: How long is each session?

Each session lasts approximately 1 hour, with practical exercises included to reinforce learning.
